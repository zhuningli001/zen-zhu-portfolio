# Homepage Copy v1 — Ningli Zhu / Zen-Zhu Studio

## Navigation

Recommended first-version navigation:

- Home
- Work
- Notes
- About
- Contact

Rationale:

- `Notes` is better than `Research` for the first version. It feels lighter, warmer, and less academic.
- `Thoughts` is also possible, but slightly softer and less structured.
- `Blog` is not recommended for the first version because it sounds too conventional and content-heavy.
- Best choice now: `Notes`.

## Homepage Strategy

The homepage should behave like a sharp editorial landing page:

- First, establish identity.
- Then show capability categories.
- Then show a visual work grid.
- Then open a quieter layer of thinking / notes.
- Finally, explain studio practice and contact paths.

The work preview should be grid-based. Each project appears as a visual card with a strong image crop, short title, project type, and capability tags. Clicking opens a case preview or full case page.

Recommended interaction:

- Default state: clean visual grid.
- Hover state: project title, role, year, tags, short one-line meaning.
- Click state: opens a project preview page or modal-style case intro.
- Later version: filter by `AI UX`, `Systems`, `Web`, `Brand`, `Culture`, `Studio`.

## Tone Rules

Use language that feels:

- Clear.
- Precise.
- Calm.
- International.
- Slightly poetic, but not vague.
- Confident without overclaiming.

Avoid:

- Too much self-branding jargon.
- Generic AI hype.
- Agency-style exaggeration.
- Over-explaining every project on the homepage.
