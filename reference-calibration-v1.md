# Reference Calibration v1 — Portfolio Visual Polish

## 1. Direction

The next visual iteration should move the prototype toward:

```text
Warm editorial index + quiet product technology + interactive visual archive
```

This means:

- Cleaner than a typical creative portfolio.
- More interactive than a static CV site.
- More human and editorial than a pure AI/product site.
- More product-system oriented than an art portfolio.

The site should feel like a personal design system that can hold projects, notes, research interests, and studio practice.

## 2. Reference Translation

### Microsoft Design

Borrow:

- Clean design-community feeling.
- Motion-forward project cards.
- Light / dark reading mode.
- Simple content filters.
- Small but distinct homepage micro-interaction.

Do not copy:

- Typography system.
- Corporate Microsoft tone.
- Too many content tags on cards.

Translation:

- Add a light / warm-dark theme toggle.
- Make work cards more visual-first and less label-heavy.
- Add one small hero micro-interaction instead of decorative AI effects.

### Google Design

Borrow:

- Cursor-circle feeling.
- Lively but precise interaction.
- Strong work-card visual presence.

Do not copy:

- Black-background direction.
- Overly Material-like playfulness.

Translation:

- Add a subtle cursor aura on desktop.
- Use pointer interaction to make the page feel designed, not static.

### Anthropic / Path to Hope

Borrow:

- Information as experience.
- Interest / research / project mapping.
- Clickable image-to-knowledge structure.
- Calm technology mood.

Do not copy:

- Direct content map structure in v0.1.

Translation:

- Keep the idea for a later `Atlas` section.
- In this polish, hint at it through a small hero signal panel and notes language.

### Component Gallery

Borrow:

- Index feeling.
- Fine grid line aesthetic.
- Distinct type personality.

Do not copy:

- Too much grid density.
- Pure directory feeling.

Translation:

- Keep grid lines extremely subtle.
- Use metadata sparingly.

### Nuevo.Tokyo

Borrow:

- Reductionist attitude.
- Industrial / systematic confidence.
- Tight project index energy.

Do not copy:

- Overly cold studio persona.
- Harsh monochrome tone.

Translation:

- Keep structure crisp, but maintain warmth and personal context.

### VAVE Studio

Borrow:

- Large visual project modules.
- Image / video-first work presentation.
- Scroll-forward project emphasis.

Do not copy:

- Huge agency hero dominance.
- Heavy brand-space studio voice.

Translation:

- Let the work grid become more image-led.
- Reduce card text to lower-left essentials.

## 3. Immediate Prototype Changes

Implement now:

1. Add light / warm-dark theme toggle.
2. Add subtle desktop cursor aura.
3. Simplify work cards further:
   - image area dominates.
   - title and short metadata sit bottom-left.
   - no status pill on grid cards.
   - no preview CTA on grid cards.
4. Add a small hero micro-interaction:
   - a compact `signal panel` inspired by type/tool controls.
   - decorative but meaningful: `clarity / structure / warmth`.
5. Make filter area more refined:
   - quieter pills.
   - clearer `Focus draft`.
   - less admin-dashboard feeling.

## 4. Later Ideas

Save for later:

- Real video/image thumbnails from projects.
- `Atlas` or `Map` module inspired by Anthropic.
- Project card motion using actual GIF/video preview.
- Full case transitions.
- More intentional typography pairings.

## 5. Style Guardrails

Keep:

- Warm off-white.
- Fine grid.
- Editorial serif + clean UI sans for now.
- Strong visual rhythm.
- Low-noise card metadata.

Avoid:

- Dark pure black.
- Neon AI glow.
- Too many pills and tags.
- Generic product landing-page gloss.
- Overdone animation.
